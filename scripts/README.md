# Scripts

Run these from the `hackpack` folder after cloning it.

- `install.sh` (macOS): installs Git, GitHub CLI, Node, Python and VS Code with Homebrew. Run `./scripts/install.sh` to see what it would do, then `./scripts/install.sh --apply` to install.
- `install.ps1` (Windows): the same with winget. Run `.\scripts\install.ps1`, then `.\scripts\install.ps1 -Apply`.
- `check.sh` (macOS and Linux): lists which tools are installed and whether you're logged in to GitHub. Changes nothing.
- `Brewfile`: the package list `install.sh` uses.

The scripts are also linked from the [setup pages](../setup/). You can read them [on GitHub](https://github.com/Jay-Jay-Tee/hackpack/tree/main/scripts) before running them.
