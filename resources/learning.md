# What to learn first

You don't need to be an experienced programmer for your first hackathon. These are the things that will let you contribute to a small web app, roughly in order.

## 1. Terminal basics

```bash
cd, ls, mkdir, pwd      # moving around
git clone, git status   # getting code
npm install, npm run dev
code .                  # open the folder in VS Code
```

## 2. Git

```bash
git status
git add -A
git commit -m "message"
git push
git pull
```

Then [guide/04-git-with-a-team.md](../guide/04-git-with-a-team.md) for working with others.

## 3. HTML and CSS

Elements, classes and flexbox. Tailwind lets you style things without much CSS knowledge.

## 4. JavaScript or Python

Pick one: JavaScript for web apps, Python for data and ML. You need variables, functions, lists and objects, conditionals, loops, making HTTP requests, and reading error messages.

## 5. React

Components, props, `useState`, `useEffect` and rendering a list. Plain HTML and JavaScript is also a perfectly good hackathon stack.

## 6. Deploying

```bash
npx vercel
```
