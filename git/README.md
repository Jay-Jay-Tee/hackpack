# Git and GitHub

Every hackathon team uses Git and GitHub to share code. These pages start from zero.

1. [What is Git?](what-is-git.md): commits, staging, branches, merging, and why any of it matters
2. [What is GitHub?](what-is-github.md): how it relates to Git, pull requests, public vs private, your profile
3. [Your first repo](first-repo.md): a 20-minute hands-on walkthrough, from an empty folder to a merged pull request
4. [Conventional commits](conventional-commits.md): a small fixed shape for commit messages, so the history explains itself
5. [SSH keys](ssh.md): logging in to GitHub with a key instead of a browser, and fixing it when it breaks
6. [Fixing mistakes](fixing-mistakes.md): "I did X, how do I undo it"

For working as a team during the event, see [Git with a team](../guide/04-git-with-a-team.md). For a quick command list, see [Commands](../resources/commands.md).
