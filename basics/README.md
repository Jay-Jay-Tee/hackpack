# How apps work

The building blocks of every web app, explained from zero: what people mean when they say API, backend, database or stack. Read in order; each builds on the last. The examples use [rain-check](../templates/example-repo.md), a small real app you can open and poke at.

1. [How the web works](how-the-web-works.md): browsers and servers, URLs, HTTP requests and responses, status codes, localhost
2. [Frontend and backend](frontend-backend.md): what runs where, frameworks, serverless, logins
3. [APIs](apis.md): what they are, JSON, calling one, making one, API keys, rate limits, CORS
4. [Databases](databases.md): tables vs documents, SQL, hosted databases, schemas, whether you need one
5. [Stacks](stacks.md): common hackathon stacks drawn out, how to choose, packages, environment variables
6. [Deploying](deploying.md): putting it online, types of hosting, fixing failed deploys

Short definitions of all these terms are in the [glossary](../resources/glossary.md).
