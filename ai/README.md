3. [Prompting AI](prompting.md): what goes into a good prompt, a workflow for real tasks, and fixing bad answers
4. [Prompt library](prompt-library.md): copy-paste prompts for every stage of a hackathon

6. [Skills](skills.md): `SKILL.md`, saved procedures your agent uses when needed, plus three ready-made ones for hackathons
