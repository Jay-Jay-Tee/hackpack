# Templates

Copy these into your project and fill them in.

- [Project README](README.template.md): what to put in your repo's README so judges can understand and run it
- [Pitch outline](PITCH.md): a three-minute structure and likely questions
- [Submission checklist](CHECKLIST.md): go through it a few hours before the deadline

To copy the raw text, open the file [on GitHub](https://github.com/Jay-Jay-Tee/hackpack/tree/main/templates) and use the copy button.
